# ♟️ Sistema de Gestión de Usuarios y Tablero

Un panel de administración y control de usuarios desarrollado con **Python (Flask)**, **SQLite** y un diseño moderno responsivo en tonos pastel con **Bootstrap 5**.

---

## 🚀 Características

* **Control de Acceso (Autenticación):** Inicio de sesión y registro de usuarios.
* **Roles y Permisos:**
  * **Administrador:** Visualización de métricas de usuarios, gráfico interactivo con *Chart.js* e información detallada emergente con *SweetAlert2*.
  * **Cliente:** Panel interactivo personalizado con estadísticas de juego y registro de actividad.
* **Seguridad:** Encriptación de contraseñas.

---

## 🛠️ Tecnologías Utilizadas

* **Backend:** Python / Flask
* **Base de Datos:** SQLite
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
* **Librerías JS:** Chart.js, SweetAlert2
